# Manifests

`mayuri_ja_filtered.list` is regenerated locally because it depends on the absolute clone path of the repository.

After downloading the full WAV release into `data/raw/wav/`, rebuild the manifest with:

```bash
python scripts/build_manifest.py
```

Tracked metadata in this directory:

- `mayuri_ja_filtered.stats.json`
- `mayuri_ja_filtered.rejects.csv`
